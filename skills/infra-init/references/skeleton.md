# 默认工作区骨架

空白运维工作区的默认组织，按信息生命周期分层。项目已有约定优先并可覆盖；存量项目不搬迁文件，只把语义到实际路径的映射写进根 `AGENTS.md`。

## 根文件（首次初始化即创建）

| 文件 | 职责 |
|---|---|
| `AGENTS.md` | 项目约定唯一入口：角色与写边界、主机与连接索引（不含秘密）、目录约定与语义映射、文档地图、录制手段与证据策略、已验证的环境坑。保持精简，稳定事实放 `knowledge/` |
| `CURRENT-STATE.md` | 当前状态权威：易变值、当前决策与风险、todo、最近观测的时间与来源 |
| `.gitignore` | 最小忽略集：`tmp/`、会话工作记忆/检查点文件（按所用客户端的实际命名）、常见观测产物 |

## 五个容器（出现第一份内容时才创建）

| 目录 | 语义 | 内部组织 |
|---|---|---|
| `knowledge/` | 稳定结构性事实 | `architecture.md`（拓扑、版本、设计）、`operations.md`（启停、巡检、手册）、`inventory.md`（硬件、资产、台账），均按需创建 |
| `history/` | 历史过程记录 | 一次窗口或事件一个 `YYYY-MM-DD-<主题>/`，主题跟随项目语言自由命名；关闭即冻结，不改名不覆盖，纠错写新记录并回指 |
| `evidence/` | 过程录制与证据索引 | 默认 `evidence/<日期>T<时刻>-<host>-<slug>.log` 加 `evidence/index.md`；命名、索引字段与入库策略由项目约定，默认见核心 `references/recording.md` |
| `assets/` | 可复用资产 | 按类型子目录按需创建：`scripts/`、`units/`、`diagrams/` 等 |
| `archive/` | 被取代的旧文档 | 归档时才建 |

## 边界规则

- **文件权限**：写出的文件与目录权限和项目既有内容保持一致，并保证目标读者可读；若所用工具产出受限权限（如 `600`），写后显式修正。
- **易变 vs 稳定**：同一易变值只在 `CURRENT-STATE.md` 出现一次；`knowledge/` 不复制易变值，`history/` 不承载"当前值"。
- **临时观测**：本地 `tmp/` 按需创建、整目录忽略、不当唯一证据；长输出先落盘再检索。过程录制放 `evidence/`，跨窗口引用时再复制或链接到 `history/<日期>-<主题>/`，并明确是否入库。
- **会话工作记忆不是项目状态**：宿主或记忆工具生成的检查点文件是 agent 临时状态，应保持被忽略，不替代 `CURRENT-STATE.md`。
- **容器名固定英文小写**；文件内容与主题语言跟随项目本身。

## 存量映射

已有目录结构的工作区：逐项盘点现有位置，在 `AGENTS.md` 写"语义 → 实际路径"映射表；没有对应位置的语义经确认后新建容器；同一语义存在多个承载位置时，交用户裁决唯一权威，不擅自合并或搬迁。
