# 装维与生产变更实施

当前上下文没有 `infra-ops-core` 时，调用 `skill` 工具加载它；已有则直接沿用，不重复加载。

## 任务形态

把已确认的目标与方案落实到目标环境。适用于初始安装、配置、升级、迁移、扩容和生产变更；授权范围只覆盖当前实施目标。

## 推进方式

1. 按核心建立或接管 todo，核对当前状态、目标对象、方案决策和已有授权。
2. 关键方案尚未确认时，先补齐设计与证据，不执行写；用户要求从现状一路交付时，说明目标扩展并加载 `infra-ops`。
3. 在实施前读取核心的 `references/change-safety.md`，交付精确变更计划并取得授权。
4. 对符合条件的低爆炸半径写执行已批准步骤；高风险或恢复依据不足的步骤交人执行，agent 提供命令、影响、恢复和验证信息。
5. 每步后读取实际后置状态，记录成功、失败和未尝试对象。出现计划偏离、意外影响或未知错误时停止扩大动作，重新授权或局部归因。
6. 完成即时后置验证；用户目标包含独立验收或完整交付时，说明目标扩展并加载 `infra-ops`，由编排器衔接后续阶段。

## 完成条件

- 所有已执行动作都能追溯到同一精确计划授权，没有静默越界；
- 每个对象的成功、失败、未尝试和未验证状态都清楚；
- 实际后置值符合预期，或偏差已停止、恢复、重新授权并如实记录；
- 状态、风险、决策和 todo 已更新，人执行步骤的可见结果也已复核。
